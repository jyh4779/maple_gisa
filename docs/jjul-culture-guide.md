# 쩔 문화 지침 문서

메이플플래닛의 "쩔" 문화에 대한 리서치 기반 지침. 콘텐츠 구성, UI/UX 설계, 기능 기획 시 이 문서를 참고한다.

---

## 1. 쩔이란?

고레벨 유저(기사)가 저레벨 유저와 파티를 맺고 메소를 받으며 경험치를 올려주는 행위. 메이플스토리 커뮤니티에서 수십 년간 이어온 문화로, 메이플플래닛에서도 활발히 성행 중. 현재는 공식 중개 채널 없이 디스코드·카카오톡 오픈채팅·게임 내 채팅에서 거래가 이루어진다.

---

## 2. 쩔의 종류

### 2-1. 방식별 분류

| 종류 | 설명 | 쩔받는 직업 |
|------|------|------------|
| **잠쩔 (잠수쩔)** | 쩔받는 사람은 첫 방에서 죽고 잠수. 기사가 혼자 사냥하며 경험치만 공유. | 모든 직업 |
| **격수쩔** | 격투가/용사 계열 전용. 기사 스펙에 따라 경험치 차등. | 격투가, 용사 |
| **프리쩔** | 프리스트 계열 전용. 30초마다 파티원에게 심(심볼)을 심어 경험치 공유. | 프리스트 |
| **파사쩔** | 파사정령의 숲 등 특정 맵 기반의 쩔. | 중저레벨 |
| **사냥쩔 / 띱쩔** | 부캐(부기)를 통해 사냥하며 경험치 공유. | 계정 소유자 |

### 2-2. 장소별 명칭

- **잠실쩔**: 잠실역 맵 기반
- **난파선쩔**: 난파선 맵 기반 (중레벨대)
- **망둥이쩔 / 오징어쩔 / 샤크쩔**: 바다 계열 사냥터 기반

> UI 설계 시 기사 프로필에 "가능한 쩔 종류" 항목을 다중 선택으로 제공할 것.

---

## 3. 거래 구조

### 거래 수단
- 인게임 메소 (현금 환산: 100만 메소 ≈ 950~1,050원)
- 현금 직거래(계좌이체)도 병행됨

### 가격 책정 방식
- 기사의 레벨·스펙·사냥 맵 효율에 따라 협의
- 단위: **탐험(탐)** 기준 (1탐 = 1회 사냥 사이클)
- 예시: 난파선 1탐 기준 경험치 900만~1200만 / 탐당 가격 협의

### 경험치 등급 (기사 스펙 기준 참고치)
| 등급 | 경험치/탐 | 비고 |
|------|----------|------|
| 빌드숙지 기사 | 약 1,000만 | 기본 수준 |
| 젠컷 기사 | 약 1,100만 | 중급 |
| 렙 낮은 젠컷 고점 기사 | 약 1,200만 | 상급 |

> 기사 프로필에 "평균 제공 경험치" 입력 필드와 후기 기반 실제 경험치 비교 표시 기능 고려.

## 4. 사기 유형 (신고 게시판 카테고리 설계 참고)

| 유형 | 수법 | 빈도 |
|------|------|------|
| **먹튀** | 메소 선결제 받고 잠적 | 최다 빈번 |
| **경험치 허위 약속** | 약정보다 낮은 경험치 제공 후 연락 두절 | 빈번 |
| **중간 이탈** | 사냥 도중 무단 이탈, 약속 시간 미채움 | 보통 |
| **허위 스펙** | 실제보다 낮은 스펙으로 비효율 사냥 | 보통 |
| **결제 내역 위조** | 계좌이체 스크린샷 조작으로 선사냥 유도 | 드물지만 고액 피해 |

> 신고 게시판 작성 폼에서 위 유형을 카테고리로 제공, 증거 파일 첨부 필드 필수화.

---

## 5. 유저가 원하는 것 (핵심 니즈)

1. **거래 전 기사 신뢰도 확인** — 사기 이력, 후기 점수, 거래 횟수
2. **이전 수혜자의 진짜 후기** — 약속 이행 여부, 실제 경험치, 태도
3. **분쟁 발생 시 증거 보존 및 커뮤니티 제재** — 신고 후 가시적인 조치
4. **기사별 사냥 맵·가격·효율 비교** — 거래 전 합리적 비교 가능
5. **연락처 없이도 기사 검색 가능** — 캐릭터명으로 이력 조회

## 6. 경쟁/유사 서비스 현황

### 플래닛폴리스
- URL: `플래닛폴리스.com`
- 기능: 이용자 제보 기반 거래 분쟁 캐릭터명 검색, 증거자료 + 당사자 해명 게시, 매크로 사용자 박제 YouTube 채널
- **한계**: 신고·박제 위주. 거래 중개·후기·신뢰도 평가·기사 프로필 기능 없음.

### 플래닛 헬퍼 (`planet-helper.com`)
- 기능: 파티 모집, 게임 DB
- **한계**: 쩔 특화 기능 없음.

### 메이플랜드 쩔 사이트 (`maplelandzzul.gg`)
- 기능: 쩔 루트/맵 정보 제공
- **한계**: 메이플랜드 전용, 중개 기능 없음.

> 우리 서비스는 기사 프로필 + 후기 + 신고가 통합된 유일한 메이플플래닛 특화 플랫폼을 목표로 한다.

## 7. 서비스 핵심 기능 축

| 축 | 기능 | 우선순위 |
|----|------|---------|
| **기사 프로필** | 캐릭터명, 직업, 레벨, 가능한 쩔 종류, 평균 경험치, 가격대 | MVP |
| **후기 시스템** | 쩔 수혜자가 남기는 별점 + 텍스트 후기, 실제 경험치 입력 | MVP |
| **신고 게시판** | 사기 유형 카테고리, 증거 첨부, 공개 여부 선택 | MVP |
| **신뢰도 조회** | 캐릭터명으로 기사 이력 즉시 검색 (사기 이력 포함) | MVP |
| **거래 비교** | 맵별·가격대별 기사 목록 필터·정렬 | 2차 |
| **에스크로 연동** | 안전 거래를 위한 메소 임치 시스템 | 3차 |
